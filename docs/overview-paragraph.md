AiTrainOps is a control‑plane + data‑plane platform for running GPU training jobs in a customer’s cloud while keeping orchestration, visibility, and governance centralized in a vendor‑hosted control plane. The key idea is separation of concerns: customers keep their data and compute inside their own AWS account or VPC, while the vendor provides the job lifecycle API, web UI, authentication, and event processing. This model enables privacy‑sensitive teams to adopt the platform without data egress, while still gaining the operational benefits of a SaaS product.

The control plane exposes APIs to submit, cancel, and inspect training jobs, and a UI that shows job status, live logs, and metrics. It persists job metadata and history in Postgres, uses an event bus (SQS FIFO by default, Kafka/MSK optionally) to ensure reliable processing of lifecycle events, and fans out live updates over WebSockets via Redis. The control plane also enforces tenant isolation and authenticates users through Clerk, providing a multi‑tenant SaaS model with organization‑scoped access.

The data plane runs inside the customer’s Kubernetes cluster. A lightweight job launcher polls the control plane, claims jobs atomically, and creates Kubernetes Jobs to execute training. Training workloads emit structured lifecycle events, logs, and metrics back to the control plane over HTTPS. This keeps the data plane simple and secure—no direct access to the event bus—while still enabling centralized observability and auditability. Deployment is streamlined via Helm charts, with configuration for control plane URLs, tenant IDs, and API tokens.

AiTrainOps is designed for teams that already run Kubernetes and GPUs but lack dedicated MLOps infrastructure. The platform provides reliable job orchestration, a consistent audit trail, and real‑time insight into training runs without forcing customers to change their code or move their data. The MVP focuses on the essentials—job submission, retries, state tracking, and live monitoring—while laying a clear path to future enhancements such as RBAC, token rotation, cost visibility, and advanced queue policies. This architecture balances enterprise‑grade controls with operational simplicity, making it practical for small‑to‑mid technical teams operating in regulated or privacy‑conscious environments.
